Website Maintenance Guide

This guide tells you how to update the website nme.fas.harvard.edu. You do not have to write code. There are 2 ways: a form for the most common changes, and Claude Code for everything else.

Website: nme.fas.harvard.edu Made by Christopher Ruaño Date: July 2026
Section 01

How the website works

The website files are on GitHub. GitHub keeps a record of each change. When a change is published, the website shows it in about 1 minute. There is no publish button and no server to log in to.

You have 2 ways to make a change:

  • A form (the easy way). For the 4 most common changes, you fill in a form on GitHub. You do not need a terminal. Refer to Section 02.
  • Claude Code (for everything else). Claude Code is an assistant on your computer. You tell it what to change in plain English. Refer to Section 03 and later.
✦

You cannot break the website permanently. GitHub keeps each change in its record. You can undo each change. Refer to Section 10.

Section 02

The easy way: use a form

For the most common changes, you do not need Claude Code or a terminal. You fill in a form on GitHub. The website prepares the change for you and opens a request. You look at the request and click one button to publish.

The forms cover these tasks

  • Add a news item
  • Add a lab member
  • Remove a lab member
  • Change text on a page

How to use a form

  1. Go to the website page on GitHub: github.com/christopherruano/carmody_lab_website.
  2. Click the Issues tab. Then click the green New issue button.
  3. Choose the form for your task. For example, Add a news item.
  4. Fill in the fields. To add a photo, drag it into the Photo box. Then click Submit new issue.
  5. Wait about 1 minute. The website adds a comment with a link to a pull request. A pull request is a change that waits for your approval.
  6. Open the pull request. Look at the change.
  7. Click the green Merge pull request button to publish. The website shows the change about 1 minute later.
!

Nothing goes live until you click Merge pull request. If the change is not correct, do not merge it. Close the pull request, or ask Claude Code to help.

✦

The forms do only the 4 tasks above. For any other change (a publication, a slideshow image, the CV, and more), use Claude Code. The prompts are in Section 05.

Section 03

First-time setup for Claude Code

Do the steps in this section one time. After this, each change takes only a few minutes. You do not need this section for the forms in Section 02.

You need these items

  • A computer (Mac or Windows).
  • A GitHub account. You are an Admin of the website. An Admin has full control. The website files are at github.com/christopherruano/carmody_lab_website.
  • Claude Code, installed on the computer. Chris or the IT team can install Claude Code. They can also sign you in. To start Claude Code, open the Terminal app, type claude, and push the Enter key.
✦

Ask a person to do one change with you the first time. Then you see all the steps one time. After this, the steps are easy.

The folder for the website

The website files are in a folder on your computer. The person who helps you makes a shortcut to this folder. You do not open the files. You start Claude Code in this folder. Then you type your request.

Section 04

How to make a change with Claude Code

Each change has the same 3 steps:

  1. Tell Claude Code what to change. Write in usual English. Give the names, the dates, and the exact words.
  2. Look at the result. Ask Claude Code to show you the change. Read it.
  3. Publish the change. Use the prompt below. The website shows the change in about 1 minute.
Prompt to publish

The change is good. Publish it to the website.

✦

You can make more than one change before you publish. Make all the changes. Look at the result. Then publish one time. If you do not see the change, refresh the page. On a Mac, push Cmd+Shift+R. On Windows, push Ctrl+F5.

Remove a news item

Prompt

Section 06

Add a photo or a file

Some Claude Code changes need a file first: a photo or a PDF. There are 2 methods. (The forms in Section 02 handle the photo for you.)

  • Method 1 (more easy): Tell Claude Code where the file is. Claude Code moves it. For example: "There is a photo on my Desktop. The name is headshot.jpg. Add it as the photo for Jane Doe."
  • Method 2 (manual): Move the file into the correct folder yourself. Then tell Claude Code that the file is there.

Section 07

Get the best result from Claude Code

These rules help you get a good result each time:

  • Give the exact words. Put the exact text in quotation marks. Claude Code uses the words that you give.
  • Change one thing at a time. One clear request is better than a long list.
  • Look before you publish. Say: "Show me the result first."
  • Correct it in plain words. If the result is wrong, say what is wrong. For example: "The date is wrong. Change it to May 3, 2026."
  • You do not need technical words. Describe what you see. For example: "The photo of John looks stretched. Please make it look correct."
  • To stop, say so. Say: "Do not publish. Undo that change."
Section 08

Other tasks Claude Code can do

Claude Code can do more than the tasks above. Here are some examples.

Check the website for problems

Prompt

Check the whole website. Find broken links, spelling mistakes, and images that do not load. Make a list of what you find. Do not change anything yet.

Get an explanation

Prompt

In simple words, tell me what the [page or file name] does. Do not change anything.

See the recent changes

Prompt

Show me a list of the changes to the website from the last month.

Ask a question

You can ask Claude Code a question in plain words. For example: "How do I add a new page to the website?" Claude Code answers the question. It can also do the task for you.

✦

Codex. Codex is a similar tool from OpenAI. It works the same way: you start it in the website folder, you type your request in plain English, and it edits the files. The prompts in this guide work with Claude Code and with Codex. Use the tool that Chris or the IT team sets up for you.

Section 10

Solve a problem

No change is permanent. GitHub keeps a record of each change. You can undo each change.

A change is wrong on the website

Prompt

Undo the last change. Then publish the correction.

You want the website as it was before today

Prompt

Change the website back to the version from before today. Then publish it.

The website does not change after 5 minutes

First, refresh the page. On a Mac, push Cmd+Shift+R. On Windows, push Ctrl+F5. If the website is still not correct, use this prompt:

Prompt

Did my last change go to GitHub? Check it. If not, publish it.

A form did not work

The website adds a comment on your issue if there is a problem. Read the comment. Check the fields that you filled in. Then submit the form again, or ask Claude Code to make the change.

Claude Code is not clear, or you are not sure

Prompt

Tell me in simple words what you will change. Do not publish yet.
