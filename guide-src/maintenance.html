Website Maintenance Guide

This guide tells you how to update the website nme.fas.harvard.edu. You do not have to write code.

Website: nme.fas.harvard.edu Made by Christopher Ruaño Date: July 2026
Section 01

How the website works

You do not have to write code. You use a tool that has the name Claude Code. You tell Claude Code what to change. Claude Code changes the files. Then Claude Code publishes the change to the website.

  • GitHub keeps the website files. GitHub also keeps a record of each change.
  • The address of the website is nme.fas.harvard.edu.
  • When you publish a change, the website shows the change in about 1 minute. There is no publish button. There is no server to log in to.
  • Claude Code is an assistant on your computer. You use a chat window to give instructions to Claude Code.
✦

You cannot break the website permanently. GitHub keeps each change in its record. You can undo each change. Refer to Section 07.

Section 02

First-time setup

Do the steps in this section one time. After this, each change takes only a few minutes.

You need these items

  • A computer (Mac or Windows).
  • A GitHub account. You are an Admin of the website. An Admin has full control. The website files are at github.com/christopherruano/carmody_lab_website.
  • Claude Code, installed on the computer. Chris or the IT team can install Claude Code. They can also sign you in. To start Claude Code, open the Terminal app, type claude, and push the Enter key.
✦

Ask a person to do one news update with you the first time. Then you see all the steps one time. After this, the steps are easy.

The folder for the website

The website files are in a folder on your computer. The person who helps you makes a shortcut to this folder. You do not open the files. You start Claude Code in this folder. Then you type your request.

Section 03

How to make a change

Each change has the same 3 steps:

  1. Tell Claude Code what to change. Write in usual English. Give the names, the dates, and the exact words.
  2. Let Claude Code make the change. Then ask Claude Code to show you the result.
  3. Tell Claude Code to publish the change. Use the prompt below. The website shows the change in about 1 minute.
Prompt to publish

The change is good. Publish it to the website.

✦

You can make more than one change before you publish. Make all the changes. Look at the result. Then publish one time. If you do not see the change, refresh the page. On a Mac, push Cmd+Shift+R. On Windows, push Ctrl+F5.

Section 04

Prompts for the usual tasks

Copy a prompt. Put it into Claude Code. Fill in the parts in [brackets]. Claude Code knows the structure of the website. You do not have to know it.

Add a news item

Prompt

Add a news item to the website. The date is [for example: July 15, 2026]. The text is: '[the news, in the exact words]'. Put the item at the top of the correct year on the News page. Put it also in the Recent News list on the home page. Keep the Recent News list to the 4 newest items. Show me the result before you publish.

Add a new lab member

Prompt

Add a new current member to the People page. The name is [full name]. The role is [for example: Graduate Student]. The email is [the address, or 'none']. The bio is: '[the bio, or 'none']'. The photo is the file [file name] in the images/people folder. Add the member to the site search also. Show me the result before you publish.

Move a member to the Former list

Prompt

Move [name] from Current to Former Laboratory Members on the People page. The destination is: '[for example: Postdoctoral Fellow, Smith Lab, Yale University]'. Update the search entry also.

Add a publication

Prompt

Add a publication to the Publications page. Put it under [the year, or 'Preprints']. The authors are [the list. Make the lab members bold]. The title is: '[title]'. The journal is: '[journal, volume, pages, year]'. The link is [the DOI or the URL]. The PDF is the file [file name] in the pdfs folder, or there is no PDF. Add it to the site search also. Show me the result before you publish.

Update the CV

Save the new CV with the name Carmody_CV.pdf. Put it in the docs folder. Replace the old file. Keep the same file name. Then use this prompt:

Prompt

Replace the CV on the website with the new Carmody_CV.pdf in the docs folder. Then publish.

Correct a mistake in the text

Prompt

On the [page name] page, change the text '[the current words]' to '[the new words]'.

Section 05

Add a photo or a file

Some changes need a file first: a photo or a PDF. There are 2 methods.

  • Method 1 (more easy): Tell Claude Code where the file is. Claude Code moves it. For example: "There is a photo on my Desktop. The name is headshot.jpg. Add it as the photo for Jane Doe."
  • Method 2 (manual): Move the file into the correct folder yourself. Then tell Claude Code that the file is there.
File typePut it in this folder
images/people/Photos of members (square, 600px or more)
pdfs/PDFs of publications
docs/The CV. Give it the name Carmody_CV.pdf
images/Images for the home-page slideshow

Section 07

Solve a problem

No change is permanent. GitHub keeps a record of each change. You can undo each change.

A change is wrong on the website

Prompt

Undo the last change. Then publish the correction.

You want the website as it was before today

Prompt

Change the website back to the version from before today. Then publish it.

The website does not change after 5 minutes

First, refresh the page. On a Mac, push Cmd+Shift+R. On Windows, push Ctrl+F5. If the website is still not correct, use this prompt:

Prompt

Did my last change go to GitHub? Check it. If not, publish it.

Claude Code is not clear, or you are not sure

Prompt

Tell me in simple words what you will change. Do not publish yet.

✦

Do you have a problem that you cannot solve? Send an email to Christopher Ruaño at chris@linklane.ai. Or ask the IT team. GitHub keeps a record of each change. A good version is always available.
